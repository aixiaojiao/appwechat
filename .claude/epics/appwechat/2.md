```javascript
const authFlow = {

```

### Backend API Specification
```
POST /auth/wechat
Request: {
  "code": "WeChat auth code",
  "appId": "mini-program app ID"
}
Response: {
  "token": "JWT token",
  "user": {
    "openId": "user open ID",
    "nickname": "user nickname",
    "avatar": "avatar URL"
  },
  "expiresIn": 3600
}
```

### Database Schema
```sql
-- Users table for storing WeChat user info
users (
  id SERIAL PRIMARY KEY,
  open_id VARCHAR(255) UNIQUE NOT NULL,
  union_id VARCHAR(255),
  nickname VARCHAR(100),
  avatar_url TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Sessions table for token management
user_sessions (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  token_hash VARCHAR(255) NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## Implementation Notes

### WeChat API Integration
- Use WeChat's `code2Session` API to validate authorization codes
- Handle WeChat API rate limits and error responses
- Store WeChat app secret securely in environment variables

### Token Security
- Use strong JWT signing algorithms (RS256 recommended)
- Implement token blacklisting for logout
- Set appropriate token expiration times (1 hour access, 30 days refresh)

### Error Handling
- Provide clear error messages for authentication failures
- Log authentication attempts for security monitoring
- Handle WeChat API downtime gracefully
