## Protocol Specifications

### Command Types
1. **Story Commands**: upload, play, pause, stop, delete
2. **Settings Commands**: set_volume, set_brightness, set_sleep_timer
3. **Control Commands**: power_on, power_off, factory_reset
4. **Query Commands**: get_status, get_story_list, get_settings

### Response Format
```json
{
  "command_id": "original-command-id",
  "status": "success|error|in_progress",
  "error_code": null,
  "error_message": null,
  "data": {
    // Response-specific data
  },
  "timestamp": 1694329397000
}
```

### Notification Format
```json
{
  "type": "notification",
  "event": "story_finished|low_battery|error",
  "data": {
    // Event-specific data
  },
  "timestamp": 1694329397000
}
```
